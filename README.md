# 🏔️ SkarduRide (React Native / Expo)

Skardu & Baltistan ke liye **InDrive / Yango** style Ride-Hailing & 4x4 Tourism Booking App.

## ✨ Features Built in Prototype
1. **Skardu Local Landmarks & Routes:**
   - Pre-loaded spots: *Yadgar Chowk, Skardu International Airport, UOBS, DHQ Hospital, Shangrila Resort, Upper Kachura, Satpara Lake, Shigar Fort, Sarfaranga Cold Desert, Kazimabad*.
   - Mountain-adjusted distance (km) & suggested fare calculation (`calculateRouteEstimate`).
2. **Skardu Vehicle Categories:**
   - 🏍️ **Moto / Bike** (Fast city commute)
   - 🚗 **Economy Car** (Alto / Cultus / Mehran)
   - 🚙 **Comfort Sedan** (Corolla / Yaris)
   - 🛻 **4x4 Prado / TZ Jeep** (Tourist & Mountain routes)
3. **InDrive-Style Fare Bidding System:**
   - Passenger apni marzi ka kiraya (`-50` / `+50` PKR) offer kar sakta hai.
   - Nearby Skardu drivers ki live **Accept** ya **Counter-Offer** bids aati hain.
4. **Dual Role Switcher (Passenger + Driver Mode in 1 App):**
   - Top bar se **Passenger** aur **Driver** mode switch kar ke dono sides test karein.
   - **Driver Commission Wallet:** EasyPaisa top-up aur har ride par 8% automatic commission deduction.
